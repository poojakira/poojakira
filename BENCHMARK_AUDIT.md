# Benchmark Audit

Date: 2026-09-16

## Reproducibility policy

A benchmark is current only when the dataset, configuration, seed, environment, command, artifact, and commit can be identified and the run is actually reproduced. A committed JSON result without a fresh run is a **historical committed result**.

## Specific claim handling

### `adversarial-ml-lab`

The README identifies a committed small-CNN CIFAR-10 run with 71.82% clean accuracy and 0.00% robust accuracy under PGD at epsilon 8/255. This should be cited as a committed experiment result, not as universal model behavior. The README also explicitly distinguishes the benchmark harness from a research contribution.

### `llm-redteam-framework`

The README reports grouped-split F1=0.97, random-split F1=1.0, and OOD novel-phrasing F1=0.83. These are configuration-specific measurements. The OOD result is the more informative generalization experiment and should remain paired with its dataset/split/seed details.

### `model-privacy-attacks`

The Adult Income MIA artifact reports AUC 0.557 with confidence intervals. This is an attack measurement, not a universal privacy threshold. No current DP epsilon benchmark was generated by this audit.

### `hf-model-provenance-scanner`

The repository's own limitation assessment already narrows 100% fixture detection claims. Keep the exact suite definition visible whenever the number is mentioned.

## Fresh execution result

No benchmark was executed locally because the environment could not clone the repositories through the local git client. Therefore this audit intentionally reports no new benchmark numbers.

## Required benchmark metadata for future runs

- repository commit SHA
- dataset name and immutable version/hash
- model architecture/checkpoint
- configuration
- random seed(s)
- Python version
- dependency lock/version set
- hardware
- exact command
- raw output artifact
- timestamp
- metric definition and sample size

## No fabricated performance claims

No new accuracy, recall, precision, AUC, epsilon, latency, throughput, detection rate, or coverage number was invented or inferred from source code.
