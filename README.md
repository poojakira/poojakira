### Narrative

My journey in machine learning began in **2021** with foundational coursework at Arizona State University, establishing a strong base in core ML concepts and programming with Python. In **2022**, I deepened my understanding through advanced ML and deep learning coursework, gaining practical experience with frameworks like PyTorch and scikit-learn, and contributing to research on e-learning systems [1]. The year **2023** marked a pivotal shift as I started exploring the nascent field of ML security, driven by an interest in the robustness of AI systems, alongside research into smart EV charging infrastructure [2].

**2024** was a year of practical application and tool building, highlighted by a practicum at the Honeywell Aerospace Innovation Hub through ASU, where I engaged with real-world AI and cybersecurity challenges. This experience catalyzed my focus on developing tangible ML security solutions. By **2025**, I was fully immersed in specialization, prototyping key ML security tools. This included developing repositories for adversarial machine learning attacks and defenses, evaluating model privacy risks, and detecting dataset poisoning [adversarial-ml-lab](https://github.com/poojakira/adversarial-ml-lab), [model-privacy-attacks](https://github.com/poojakira/model-privacy-attacks), [dataset-poisoning-detector](https://github.com/poojakira/dataset-poisoning-detector).

The **2026** phase has been dedicated to hardening and deploying these ML security capabilities. My work has expanded to include critical areas such as Hugging Face model provenance scanning, LLM red-teaming frameworks, monitoring for prompt injection and data exfiltration in MCP tool calls, and integrating secure MLOps practices into projects like NASA C-MAPSS RUL forecasting. This culminated in the development of a [unified-ml-security-platform](https://github.com/poojakira/unified-ml-security-platform) that integrates these production-grade security controls.
