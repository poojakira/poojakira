## AI / ML Security Engineer

**Agent security · MCP/tool-call security · model supply-chain integrity · LLM red teaming · adversarial ML**

I build and test security controls around AI systems after they become operational: when a model calls tools, reads untrusted data, loads artifacts, receives cloud identity, or produces actions that need auditability.

My current work is centered on agent runtime security and evidence-backed ML security engineering: least-privilege agent identity, MCP/tool policy boundaries, model artifact inspection, prompt-injection evaluation, privacy-risk experiments, dataset poisoning, and reproducible security checks in CI.
