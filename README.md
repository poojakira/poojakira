## 🚀 Key Flagship Projects

### 🛡️ [Model-Supply-Chain-Auditor](https://github.com/poojakira/Model-Supply-Chain-Auditor)
- **What**: A specialized tool for verifying the integrity and safety of ML model artifacts (`.safetensors`, `.pt`, `.pkl`).
- **Security Angle**: Deep static pickle scanning for RCE, Ed25519 model signing/provenance, and policy-driven CI/CD gates.

### 🤖 [LLM-Guard-Scanner](https://github.com/poojakira/LLM-Guard-Scanner)
- **What**: Multi-layered security guardrail for LLM and RAG applications.
- **Security Angle**: Real-time detection of prompt injection (LLM01), PII leakage (LLM02), and RAG poisoning (LLM03).

### 🛰️ [PulseNet-RUL-Forecasting](https://github.com/poojakira/PulseNet-RUL-Forecasting)
- **What**: Production-grade predictive maintenance platform for NASA turbofan telemetry.
- **Security Angle**: Zero-trust architecture with tenant isolation, hash-chained audit logs, and verifiable data lineage.

### ☁️ [production-ml-platform](https://github.com/poojakira/production-ml-platform)
- **What**: Hardened ML control plane for serving, experiment tracking, and drift monitoring.
- **Security Angle**: Mandatory RBAC for all platform actions, authenticated APIs, and automated security quality gates.

### 🔒 [Secure-ML-platform](https://github.com/poojakira/Secure-ML-platform)
- **What**: Reference implementation for secure ML inference and model protection.
- **Security Angle**: Focus on inference-time threats like model extraction, token abuse, and log tampering.

### 🧪 [ML-Privacy-Attacks](https://github.com/poojakira/ML-Privacy-Attacks)
- **What**: Research framework for evaluating and mitigating privacy leakage in ML models.
- **Security Angle**: Implementation of membership inference and model inversion attacks paired with DP-SGD defenses.

### ⚔️ [Adversarial-Robustness-Toolkit](https://github.com/poojakira/Adversarial-Robustness-Toolkit)
- **What**: Toolkit for evaluating and enhancing model resilience against adversarial examples.
- **Security Angle**: Robustness benchmarking of FGSM/PGD attacks vs. Adversarial Training and TRADES defenses.
